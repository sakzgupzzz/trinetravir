# Khatri lab Meta-Virus Signature (MVS) module genes
# Source: Andres-Terre et al. 2015 Immunity (and Mostafavi et al. 2016 Cell parallel work).
# Acquired 2026-05-11 as part of Session 5 Part B external validation.
#
# This is the canonical viral-induced gene module reported by the Khatri group across
# multiple human PBMC bulk RNA-seq cohorts spanning IAV, RSV, dengue, ebola, and other
# RNA viruses. The list is composed of canonical type-I-IFN-stimulated genes (ISGs)
# plus a small set of co-regulated immune effector genes.
#
# For Session 5 Part B external validation: we use this gene list as the reference
# signature; our v1 harmonized cross-study response vectors should correlate with the
# bulk PBMC response vector restricted to these genes if our calibration framework is
# capturing the viral-response signal.
#
# Full ~396-gene list is on Khatri lab GitHub (https://github.com/khatri-lab) +
# Andres-Terre 2015 Table S2. For Session 5, we ship the canonical high-confidence
# core subset (Type-I-IFN ISGs that are universally up-regulated across all Khatri
# cohorts). This is the most defensible anchor for v1 monocyte cross-virus comparison.
