# Trinetravir

Cross-virus transfer learning for single-cell host response prediction.

Single-cell foundation models and perturbation prediction methods are typically evaluated within a single virus or perturbation system. This project benchmarks cross-virus transfer — training on host response to one virus and predicting response to another the model has never seen — and develops a factorized architecture that separates shared antiviral programs from virus-specific responses.

Status: early development. See [PLAN.md](./PLAN.md) for the current project specification.
